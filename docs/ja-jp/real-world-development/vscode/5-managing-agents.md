GitHub Copilot をエージェントモードで使うと、コードベースを調べ、変更を提案し、ファイルを編集し、コマンドを実行します。VS Code の Copilot Chat では、その作業がローカル環境でリアルタイムに進むため、ツール呼び出しやファイル編集を確認できます。差分をインラインでレビューし、個々の変更を適用または取り消し、エディターを離れずに追加のプロンプトを送って作業を調整または拡張できます。

この演習では、次の内容を学びます。

- アクセシビリティエージェントの作業をリアルタイムに監視します。
- 提案されたファイル編集をレビューし、適用します。
- セッション中にエージェントへ指示を追加し、高コントラストに加えてライトモードの切り替え機能を実装します。

## シナリオ

[演習 4][previous-lesson] で使ったアクセシビリティ用カスタムエージェントは、高コントラストモードを実装中です。作業中にデザインチームから追加の要望がありました。既定のテーマが暗すぎると感じるユーザー向けに、ライトモードも切り替えられるようにします。新しい会話を始める代わりに、現在のセッションに指示を追加して作業を拡張します。

## Copilot の進行状況を監視する

Copilot Chat ビューには、エージェントが実行する各ステップが表示されます。調べたファイル、実行したコマンド、提案した編集を確認できます。各ファイルの編集は差分と **Keep** / **Undo** の操作とともにチャットに表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、ツールの呼び出しを確認します。ファイルの読み取りや編集、実行許可を求めるターミナルコマンドなどが表示されます。
3. エージェントがファイルの編集を提案すると、差分がチャットに表示されます。
    - 変更を適用するには **Keep** を選択します。
    - 変更を元に戻してエージェントに再度作業させるには **Undo** を選択します。
4. チャット上部の **Files changed** を開くと、このセッション中にエージェントが変更したすべてのファイルを確認できます。

> [!NOTE]
> ツールの呼び出し (ターミナルコマンドの実行など) で許可が必要な場合、エージェントは一時停止して **Allow** を表示します。内容を確認し、問題ないコマンドだけを許可してください。

5. 高コントラストモードの実装が完了するまで待ちます。最後に、変更内容をまとめたメッセージが表示されます。

## エージェントにライトモードを追加するよう指示する

高コントラストモードができたら、同じ会話でライトモードの切り替えを追加します。同じチャットセッションを続けるため、エージェントは先ほどの作業、変更したコンポーネント、スタイルの方針、local storage を使った設定の保存方法を把握しています。

1. Copilot Chat の入力欄に、次の追加プロンプトを送信します。

    ```plaintext
    Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
    ```

2. エージェントは既存の変更を確認し、ライトモードの追加を提案します。
3. 高コントラストモードのときと同じように、新しい編集を確認して **Keep** または **Undo** を選択します。
4. エージェントの方針が希望と異なる場合 (たとえば、切り替え UI を望まない形で再構成しようとした場合) は、チャット入力欄の横にある **Stop** ボタンで停止し、追加の説明を送信します。

> [!TIP]
> 作業中のセッションに指示を追加すると、最初からやり直すより短時間で修正できます。追加のプロンプトで調整を依頼できます。たとえば、「CSS を簡潔にして、セレクターの重複ではなく CSS 変数を使う」、「3 つ目のトグルを追加せず、既存の設定パネルにライトモードを組み込む」、「両方の切り替えにキーボードショートカットも追加する」などです。

## 作業内容をレビューする

コミットする前に、エージェントが変更した内容を確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧をすべて確認します。Astro コンポーネント、スタイル、関連テストなどが更新されているはずです。
3. 変更されたファイルをいくつか開き、差分を確認します。カスタムエージェントが示したアクセシビリティのパターン (ARIA 属性、キーボード操作、セマンティック HTML、local storage による設定の保存など) が反映されていることを確認します。
4. 問題がなければ、Source Control パネルから変更をステージングしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェントモードで、進行中のセッションを監視して方向付けました。ファイルの編集を確認して適用または取り消し、コンテキストを保ったまま追加のプロンプトを送って作業を拡張しました。

このレッスンでは、次の内容を学びました。

- エージェントの作業をリアルタイムに監視する方法
- 個々のファイル編集を適用または取り消す方法
- 追加のプロンプトを使って、作業中のセッションを調整する方法
