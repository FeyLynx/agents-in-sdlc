**[GitHub Copilot app][about-copilot-app]** は、エージェント主導の開発に使用するデスクトップアプリケーションです。GitHub Copilot CLI を基盤とし、GitHub とネイティブに統合されているため、リポジトリ、ブランチ、CI パイプラインをすぐに利用できます。すべての作業を自分で行うのではなく、それぞれ独立したワークスペースで複数のエージェントを並列に指示するワークフローや、繰り返し作業の自動化に向いています。Node.js がインストールされ、プロジェクトの自分用コピーも準備できたので、次はアプリをインストールしてリポジトリを接続します。

このレッスンでは、次の内容を学びます。

- GitHub Copilot app をインストールしてサインインします。
- GitHub リポジトリからプロジェクトをアプリに追加します。
- テンプレートによって用意されたバックログなど、ワークスペースを確認します。
- クイックチャットを試して、アプリについて質問します。

## シナリオ

チームでは、増え続けるバックログに対応するために AI エージェントを導入しています。Copilot app では、Issue の選択、エージェントの実行、変更のレビュー、プルリクエストのマージを一か所から指示できます。このレッスンでは、アプリをインストールして接続し、プロジェクトについての会話を始められるようにします。

> [!NOTE]
> 対象となる Copilot プランが必要です。Copilot Free、Copilot Student、または有料プラン (Pro、Pro+、Business、Enterprise) を利用してください。Copilot Business または Copilot Enterprise では、管理者が **GitHub Copilot app** ポリシーを有効にする必要があります。

## GitHub Copilot app をインストールして構成する

GitHub Copilot app を使うには、まずアプリをインストールします。Windows、macOS、Linux 向けのバージョンが用意されています。アプリをインストールして認証し、Tailspin Toys リポジトリを追加します。

1. ブラウザーで [GitHub Copilot app のランディングページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ランディングページの手順に従ってインストールします。
3. インストールが完了したら、アプリを開きます。
4. **Sign in to GitHub** を選択し、画面の指示に従って認証します。データ所在地を利用する GitHub Enterprise Cloud を使っている場合は、**Use GitHub Enterprise** を選択し、求められたら `*.ghe.com` のホスト名を入力します。GitHub Enterprise Server には対応していません。
5. オンボーディング中にリポジトリの選択画面が表示された場合は、テンプレートから作成した Tailspin Toys リポジトリを選択します。リポジトリの選択をスキップし、オンボーディング後にプロジェクトを追加することもできます。
6. テーマを選ぶよう求められたら選択し、オンボーディングを完了します。
7. サイドバーの **Sessions** にリポジトリが表示されているか確認します。すでに一覧にある場合は、再度追加する必要はありません。
8. リポジトリがまだ接続されていない場合は、**Sessions** の横にある **+** を選択して新しいセッションを作成し、**Add GitHub repository** を選択します。前提条件のレッスンで記録した所有者とリポジトリ名を入力します。
9. リポジトリがサイドバーに表示されていることを確認します。このレッスンで使うレイアウトでは、`tailspin-toys` などのリポジトリフォルダーが **Sessions** の下にグループ化され、各リポジトリの下に個々のセッションが表示されます。

## ワークスペースを確認する

プロジェクトを接続したら、アプリの使い方を確認しましょう。サイドバーには、いくつかの領域があります。

- **New**: 新しいチャットセッションを開始します。
- **Pull requests**: アプリの GitHub ネイティブ統合を通じてプルリクエストを表示します。アプリを離れずに参照や絞り込み、CI 状態の確認、レビューを行えます。
- **Issues**: Issue を表示します。参照や絞り込みを行い、Issue からセッションを開始できます。
- **Automations**: スケジュールまたはオンデマンドで実行する、保存済みのエージェントタスクです。To Do リストの管理、定期的なプロジェクト保守、その他の面倒な作業を任せるのに役立ちます。振り返りでは次のステップとして紹介しますが、別の演習ではありません。
- **Customize**: MCP サーバー、プラグイン、スキルなどのコンポーネントを追加して、Copilot app の機能を拡張します。Playwright MCP の設定に使用します。
- **Chats**: ブランチや独自のワークスペースを必要としない、質問やブレインストーミング向けの簡易的な会話です。最初のチャットを開始すると、このセクションが表示されます。表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを始めます。
- **Sessions**: リポジトリフォルダーと、その中のエージェントセッションをまとめます。`tailspin-toys` などのリポジトリ名を選択するとリポジトリビューが開き、その下のセッションを選択すると会話に戻ります。セッションはそれぞれ独立したワークスペースで実行されるため、変更が競合せず、複数を同時に実行できます。ゲームカードへの星評価追加で最初のセッションを開始します。

ワークショップを進めながら、ワークスペースを確認していきます。

> [!TIP]
> 迷ったときは Copilot に質問しましょう。操作方法がわからない場合や、何かが可能かどうか知りたい場合は、Copilot に尋ねると案内してくれます。

### 用意されたバックログを確認する

バックログのないプロジェクトはほとんどなく、Tailspin Toys も例外ではありません。テンプレートからリポジトリを作成したときに用意されたバックログを確認します。

1. サイドバーの **Sessions** で、Tailspin Toys のリポジトリフォルダーを選択します。下にある個別のセッションは選ばないでください。次に、リポジトリ上部のナビゲーションで **Issues** を選択します。
2. Issue 番号を決めつけず、タイトルで次の Issue を探します。

   - Allow users to filter games by category and publisher
   - Update our repository coding standards

3. Issue を選択して詳細を読みます。Issue はエージェントセッションを開始する場所にもなります。簡単な最初の変更が終わったら、フィルター機能の Issue から作業を開始します。

> [!NOTE]
> **Issues** と **Pull requests** の一覧には、Copilot app に追加したリポジトリの項目だけが自動的に表示されます。ほかのリポジトリの作業項目を見るには、そのリポジトリもアプリに追加してください。

## クイックチャットを試す

アプリ自体について質問すると、アプリに慣れるのに役立ちます。その用途には **クイックチャット**が適しています。クイックチャットでは、ブランチや worktree を作らずに質問やブレインストーミングを行えます。専用のセッションを必要としない、簡単な質問に最適です。

1. サイドバーで **Chats** の横にある **+** を選択して新しいチャットを開きます。**Chats** がまだ表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始します。開始後に **Chats** が表示されます。
2. アプリのセッションについて質問します。

   ```plaintext
   How does the GitHub Copilot app use worktrees?
   ```

3. 会話ビューで回答を読みます。各セッションが分離された独自の git worktree で実行されるため、変更が競合せず、複数のエージェントを並列に実行できることがわかります。会話はいつでも続けられ、新しいチャットも開始できます。

- GitHub リポジトリからプロジェクトを追加する。
- ワークスペースを確認し、**Issues** で用意されたバックログを見つける。
