**[GitHub Copilot CLI][about-copilot-cli]** を使うと、ターミナルでエージェント型コーディングアシスタントとして GitHub Copilot を利用できます。コードベースを調べ、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンドラインから行えるため、グラフィカルエディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys で一連の開発ワークフローを実践します。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして使い方を確認します。
2. 星評価の小さな変更を実装し、ブラウザーでレビューして、最初のプルリクエスト (PR) を手動でマージします。
3. フィルター機能の Issue から始め、Plan モードで方針を決め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルター機能の作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズして、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルター機能を確認します。
7. 品質保証 (QA) カスタムエージェントを作成して、要件、カバレッジ、検証の根拠をレビューします。
8. フィルター機能の変更全体をレビューし、Agent Merge を使って PR を処理します。
9. コンテキスト、モデル、共有、省略可能な cloud agent への委任に使う便利なスラッシュコマンドを確認します。

ワークショップの焦点を絞るため、PR は 2 件作成します。1 件目は星評価、2 件目は指示、スキルの更新、QA プロファイル、テストを含むフィルター機能です。各ツールの使い方を学びながら作業を積み上げられるよう、フィルター機能と品質ワークフローでは同じ会話とブランチを使います。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかのプランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランを利用していない場合、認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれます。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合、管理者が Copilot CLI を有効にしていることを確認してください。
