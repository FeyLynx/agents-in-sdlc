通过贴近实际的场景、完整应用和共享待办事项，探索 GitHub Copilot 在软件开发生命周期中的应用。你将通过迭代规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为桌游提供众筹服务，并以开发者为主题。团队的待办事项已作为 GitHub 议题创建，随时可以开始处理。其中既有筛选和分页等功能任务，也有无障碍访问和编码标准等质量改进任务。

## 选择工作环境

GitHub Copilot 可以融入你使用的工作环境。选择最适合你的构建方式。每个研讨会都有自己的设置流程，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright MCP、Agent Merge，以及实用的斜杠命令。

### [GitHub Copilot app][app]

运行并行的智能体会话、切换会话模式、在画布上协作，并在桌面应用中管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
